# /yt-source-finder — 소재 찾기

입력: `$ARGUMENTS` (비어 있으면 "반려동물 용품"으로 시작)

## 1. 데이터 수집

1. `YT_API_KEY` 환경변수가 있으면 스크립트를 먼저 돌린다.
   ```bash
   python scripts/find_trending.py --query "$ARGUMENTS" --days 14 --max 40 --json /tmp/trending.json
   ```
   키워드는 2~4개로 넓혀서 여러 번 돌린다 (예: "고양이 털", "강아지 산책 용품", "집사 꿀템").
2. 키가 없거나 결과가 적으면 웹 검색으로 보완한다 (유튜브 쇼츠 인기 영상, 쿠팡/네이버 반려동물 베스트, 커뮤니티 화제글).
   이 경우 `01_소재.md`에 **"API 수치 없음 — 웹 검색 기반 추정"**이라고 분명히 적는다. 조회수를 지어내지 않는다.

## 2. "터진 영상" 판단 기준

스크립트가 계산해 주는 값을 기준으로 삼는다.
- **일평균 조회수** = 조회수 ÷ 업로드 후 경과일
- **구독자 대비 배율** = 조회수 ÷ 채널 구독자 수 (1배 이상이면 알고리즘이 밀어준 영상으로 본다)
- 업로드한 지 14일 이내만 본다.

## 3. 패턴 추출

상위 영상 5~10개를 보고 다음을 정리한다.
- 첫 3초 훅 (문장이나 장면)
- 다루는 문제 상황 (털 날림, 분리불안, 산책 중 당김 등)
- 영상 형식 (비포/애프터, 실험, 랭킹, 공감 상황극)
- 댓글에서 많이 나오는 반응이나 질문

## 4. 소재 선정

후보 3개를 만들고 각각 점수를 매긴다 (각 1~5점).
- 수요: 조사한 영상들이 실제로 터졌는가
- 상품 연결: 쿠팡에서 살 수 있는 상품 하나로 해결되는가
- 차별화: 우리 채널 형식(실제 상품 사진 + 문제 해결형 내레이션)으로 다르게 보여줄 수 있는가
- 팩트 안전성: 효능을 과장하지 않고도 설득이 되는가

가장 높은 점수의 소재 하나를 고른다.

## 5. 출력

`CLAUDE.md`의 규칙대로 slug와 상품 번호를 정하고 `content/<slug>/01_소재.md`를 아래 형식으로 쓴다.

```markdown
# 소재: <한 줄 요약>
- slug: <slug>
- 상품 번호: <번호>
- 쿠팡 검색 키워드: <auto_shorts.py에 넣을 keyword>
- 데이터 출처: YouTube Data API (조회일 YYYY-MM-DD) | 웹 검색 기반 추정

## 레퍼런스 영상
| 제목 | 채널 | 업로드 | 조회수 | 일평균 | 구독자 대비 | 훅 |
|---|---|---|---|---|---|---|

## 관찰된 패턴
## 후보 소재 3개와 점수
## 선정 소재와 이유
## 대본 작가에게 넘길 메모
- 타깃 시청자 / 핵심 고통 / 꼭 넣을 장면 / 피해야 할 표현
```

마지막에 다음 단계로 `/yt-scriptwriter <slug>`를 안내한다.
