# /yt-scriptwriter — 대본 쓰기

입력: `$ARGUMENTS` = slug. 비어 있으면 `content/`에서 `02_대본.md`가 없는 가장 최근 폴더를 쓴다.
`content/<slug>/01_소재.md`가 없으면 멈추고 `/yt-source-finder`를 먼저 돌리라고 안내한다.

## 대본 구조 (세로 쇼츠, 30~45초)

| 씬 | 역할 | 길이 | 비고 |
|---|---|---|---|
| 1 | 훅 | 2~3초 | 시청자의 고통을 1인칭 공감으로 바로 찌른다. 인사·채널 소개 금지 |
| 2 | 문제 심화 | 4~6초 | 기존 방법이 왜 안 되는지 |
| 3 | 해결 등장 | 4~6초 | 상품을 처음 보여준다 |
| 4~5 | 작동 원리 / 시연 | 각 5~7초 | 눈으로 확인되는 장면 위주 |
| 6 | 보너스 이점 | 4~6초 | 세척·내구성·가격 등 확인된 사실만 |
| 7 | 행동 유도 | 3~4초 | "프로필 링크 [집사연구소]에서 <번호>번" |

## 작성 원칙

- 내레이션은 한 씬에 한 문장, 25자 안팎. 말로 읽었을 때 자연스러운 구어체.
- 자막(`subtitle`)은 내레이션을 그대로 옮기지 않고 핵심만 18자 이내로 줄인다. 강조할 단어 하나를 `**굵게**` 표시한다.
- 화면(`visual`)은 편집자가 그대로 만들 수 있게 구체적으로 쓴다: 어떤 이미지, 어떤 움직임, 어떤 텍스트 효과.
- 효능이나 수치를 말할 때마다 근거를 `근거` 열에 적는다 (상품 상세페이지, 제조사 설명, 리뷰 경향 등). 근거가 없으면 그 문장을 쓰지 않는다.
- 금지 표현: "100%", "완벽하게", "무조건", "의사도 추천" 같은 확인 안 되는 단정.
- 반려동물 건강·안전과 관련된 주장(사료, 영양제, 진정 효과 등)은 쓰지 않거나 "수의사와 상담하세요"를 붙인다.

## 출력: `content/<slug>/02_대본.md`

```markdown
# 대본 초안: <제목 가안>
- slug / 상품 번호 / 예상 길이(초)

| # | 역할 | 내레이션 (TTS) | 자막 | 화면 | 근거 |
|---|---|---|---|---|---|
| 1 | 훅 | ... | ... | ... | - |

## 작가 메모
- 이 훅을 고른 이유, 대안 훅 2개
```

마지막에 `/yt-script-review <slug>`로 넘기라고 안내한다.
