# /yt-script-review — 대본 검수

입력: `$ARGUMENTS` = slug. `content/<slug>/02_대본.md`가 없으면 멈추고 `/yt-scriptwriter`를 먼저 돌리라고 안내한다.

작가와 다른 사람이라는 생각으로 본다. 칭찬보다 문제를 찾는 게 일이다.

## 4가지 기준 (각 10점)

### ① 초반 3초 훅
- 첫 문장만 듣고 스크롤을 멈출 이유가 있는가?
- 인사, 채널 소개, "오늘은 ~를 소개할게요" 같은 도입이 있으면 바로 감점.
- 첫 화면에 움직임이나 대비(비포/애프터)가 있는가?

### ② 시청자 심리
- 타깃 집사가 실제로 겪는 장면인가? (구체적인 장소·물건·상황)
- 문제 → 해결 → 이점으로 긴장이 이어지는가, 중간에 늘어지는 씬은 없는가?
- 씬 하나가 7초를 넘으면 쪼개거나 줄인다.

### ③ 팩트 체크
- 대본의 모든 주장을 표로 뽑아 `근거 있음 / 약함 / 없음`으로 분류한다.
- `없음`은 삭제하거나 확인 가능한 표현으로 바꾼다. `약함`은 표현 수위를 낮춘다 ("싹 다" → "대부분").
- 반려동물 건강·안전에 관한 주장, 다른 브랜드 비하, 가격 단정("최저가")이 있으면 반드시 고친다.

### ④ 마케팅 / 전환
- 상품 번호와 "프로필 링크 [집사연구소]" 안내가 정확한가?
- 행동 유도 직전에 "왜 지금 사야 하는지"가 있는가 (과장 없이)?
- 댓글을 유도하는 장치가 있는가? 댓글 봇 키워드 `유튜브`를 쓰면 안내 링크가 자동 답글로 달린다 (`comment_bot/config.json` 참고).

## 판정

- 총점 32점 이상, 팩트 항목 8점 이상: **통과**
- 그 밖: **수정 후 재검수**. 고친 버전으로 다시 채점해 통과할 때까지 반복한다 (최대 3회).

## 출력

1. `content/<slug>/03_검수.md`
   ```markdown
   # 검수 결과: <slug>
   | 기준 | 1차 점수 | 최종 점수 | 핵심 지적 |
   |---|---|---|---|
   ## 팩트 체크 표
   | 주장 | 근거 | 판정 | 조치 |
   ## 문장 수정 내역 (전 → 후)
   ## 판정: 통과 / 재검수
   ```
2. `content/<slug>/02_대본.md`를 확정본으로 덮어쓰고 제목 줄을 `# 확정 대본: ...`으로 바꾼다.

마지막에 `/yt-publisher <slug>`로 넘기라고 안내한다.
