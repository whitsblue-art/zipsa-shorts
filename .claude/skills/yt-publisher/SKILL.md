# /yt-publisher — 제목·썸네일

입력: `$ARGUMENTS` = slug. `02_대본.md`의 제목 줄이 `# 확정 대본`이 아니면 멈추고 `/yt-script-review`를 먼저 돌리라고 안내한다.

## 제목 후보 (3~5개)

- 쇼츠 제목은 피드에서 잘리므로 **앞 20자 안에 핵심**을 넣는다. 전체 40자 이내.
- 후보마다 다른 공식을 쓴다:
  1. 고통 공감형: "돌돌이로 안 되는 소파 털, 이걸로 끝"
  2. 호기심 갭형: "집사들이 몰래 쓰는 털 청소 도구"
  3. 비포/애프터형: "5초 만에 털 뭉치가 된 소파"
  4. 숫자·대상 지정형: "장모종 집사라면 꼭 봐야 할 1가지"
- 대본에 없는 약속을 제목에 넣지 않는다 (낚시 제목은 시청 지속률을 떨어뜨린다).
- 각 후보에 예상 강점·약점 한 줄, 그리고 추천 1순위를 표시한다.

## 썸네일(쇼츠 커버 프레임) 구성안

Remotion의 `Cover` 씬(첫 프레임)으로 그대로 들어가므로 아래 필드를 정확히 채운다.
- `headline`: 8자 이내 큰 문구 (예: "털 지옥 탈출")
- `subline`: 14자 이내 보조 문구
- `highlight`: headline 중 강조색(골드 #D4AF37)으로 칠할 단어
- 레이아웃: 상단 1/3 문구, 가운데 상품 이미지, 하단 비포/애프터 또는 상품 번호 배지
- 1080×1920 기준, 위아래 각 250px은 유튜브 UI에 가려지므로 핵심 요소를 두지 않는다.

## 설명란 / 태그 / 고정 댓글

- 설명란 첫 줄: 제목을 반복하지 말고 영상 핵심 한 문장 + 상품 번호.
- 쿠팡 파트너스 고지 문구 필수 (`CLAUDE.md` 참고).
- 해시태그 3~5개 (#쇼츠 #집사 #반려동물용품 + 소재 관련 2개).
- 고정 댓글: 상품 번호 안내 + "궁금한 점은 댓글에 '유튜브'라고 남겨주세요 → 안내 링크를 답글로 보내드려요" (댓글 봇 키워드).

## 출력: `content/<slug>/04_퍼블리시.md`

```markdown
# 퍼블리시 패키지: <slug>
## 제목 후보
| 순위 | 제목 | 공식 | 강점 | 약점 |
## 썸네일
- headline / subline / highlight / 레이아웃 설명
## 설명란
## 해시태그
## 고정 댓글
```

마지막에 `/yt-editor <slug>`로 넘기라고 안내한다.
